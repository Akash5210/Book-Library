# booklibrary

This project is created to perform CRUD operation in which we can view book details, add new, update it or delete it. 
The technologies which is have used to create this project are: Vue 3 javascript framework, Element plus for css styling, pinia for state management, google firebase for authentication.

## Project Setup

```
npm install
```

### Compile and Hot-Reload for Development

```
npm run dev
```

### Compile and Minify for Production

```
npm run build
```
### Deploy latest app on firebase

```
firebase deploy
```
